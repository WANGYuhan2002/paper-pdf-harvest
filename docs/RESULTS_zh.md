# 实测覆盖率、优点与不足

[English](RESULTS.md) · **中文**

## 数据来源

以下是一个 SeismoHub 文献库的抓取报告的汇总数字：2026 年 11 月 8 日至 10 日的 18 次文献库模式运行，涉及 2,445 篇
不同的论文（共 4,845 篇次）。数字只由报告元数据算出（状态、渠道、层级、DOI 前缀、期刊），没有打开任何 PDF 或许可
副本。

背景很重要：

- **领域：**地震学与地球物理学，以 2025–2026 年的论文为主，另有经典文献和预印本。
- **密钥：**配置了 Wiley TDM 令牌、Elsevier API 密钥和 OpenAlex 密钥。
- **网络：**部分运行在机构网络内，Elsevier 订阅 XML 需要这一点。
- **引擎版本：**这些运行跨越三天的开发期。旧报告里有些渠道名（`gfz_repo`、`hal_api`、`datacite_repo`、
  `crossref_preprint`）是当时的独立步骤，现在由 `green_oa_cascade` 一起执行；`s2_oa`（Semantic Scholar）后来已经去掉。

每篇论文取所有运行中的最好结果：开放副本优于许可副本，许可副本优于什么都没有。

205 个许可副本中有 26 个是 11 月 9 日封印之前的一次早期运行挂上去的，之后已解除挂接，与其他许可副本一样扣在本地。

1,562 个开放副本中，865 个是正式版，22 个是录用稿，599 个是投稿版或预印本，76 个版本不明。其中 437 个经许可的 TDM

这 286 篇大多要另找途径，因为 AGU 和 Wiley 网站屏蔽脚本。

没有全文的论文按状态：`no_oa_copy` 547、`captcha_or_bot_block` 47、`transient_error` 17、`unsupported` 9、
`auth_required` 9、`unsupported_content_type` 8。

作为对照，整个文献库（2,503 篇，含手动上传的 PDF）有 1,556 篇（62%）挂了 PDF。

## 优点

- **拿到的是对的副本。**每个 PDF 都要过四道校验，其中包括对照标题和 DOI 的身份校验，把预览、登录页、会议摘要和下错
  的论文挡在外面。arXiv 渠道 717 次下载中有 716 次通过。
- **在机制上保证许可正确。**层级按实际下载到的副本判定，参考 Crossref 的第二意见，并复查 PDF 自身的文字。许可副本
  一律扣下、不外发；即使引擎被打了补丁，封印也照样有效。
- **基础设施开放的地方覆盖率很高：**EarthArXiv、Seismica、MDPI、Nature 旗下、arXiv 和 ETH Research Collection 都在
  94%–100%。有 Wiley 令牌时 AGU 达到 99%（开放 79%，许可 20%）；在有权限的网络内 Elsevier 达到 100%（开放 61%，
  许可 XML 39%）。
- **礼貌、透明。**每个站点有请求间隔，有熔断，绝不绕过。每一次尝试都记录 URL、HTTP 状态和原因，所以任何一篇缺失的
  论文都能说清为什么。
- **缺口有人管，不藏着。**每篇缺失的论文都会在清单里占一行，附链接和下一步；`triage` 用同一套许可规则把浏览器下载的
  文件导回来。
- **不只是 PDF，而是一整包材料：**EGU 的 XML 和公开评审意见、Elsevier 的 XML 连同插图和补充材料、Nature 的补充材料，
  以及代码和数据链接。

## 不足

- **屏蔽脚本的出版商。**GeoScienceWorld（SSA 期刊，开放 14%）、OUP（2024 年以前的 GJI）、ESSOAr（16%）、Science、
  PNAS，以及 AGU、Wiley 和 ScienceDirect 网站，都拦截脚本下载。没有 TDM 接口、别处也没有开放副本时，这些论文只能用
  浏览器下载。工具不会绕过。
- **没有 TDM 途径的订阅期刊**（SEG 5%、SSA）只能靠别处的开放副本，而这些期刊的开放副本很少。
- **Elsevier 订阅文章只能拿到 XML，拿不到 PDF**，而且只能在有权限的网络内获取。`render-xml` 能生成可读的 PDF，但不是
  出版商的排版。
- **Wiley TDM 时好时坏。**329 次尝试以 HTTP 500 或超时告终，几天后重跑就成功了。10 秒的间隔也让大批 Wiley 论文跑得
  很慢。
- **OpenAlex 缓存有配额：**免费密钥每天大约 100 个 PDF。
- **绿色开放获取级联的产出很低。**316 次尝试只命中 20 次。它是成本很低的最后手段，不是主力渠道。
- **Zenodo 的 DOI 大多是数据集和软件。**109 个中有 96 个没有论文 PDF。这本身没错，但会显示为缺失。
- **身份校验是启发式的。**改了标题、作者又少于三位的预印本会被拒（漏判）。两篇论文共用一个很笼统的标题时，理论上
  可能误判通过；有 DOI 和合作者规则把关，这种情况不太可能出现。
- **浏览器下载的许可分流依赖文字标志**（CC 声明、"All rights reserved"、机构下载水印），而且大多是英文。它从严处理，
  但识别不了所有订阅 PDF。
- **针对地学调过参数：**金色开放获取期刊表、屏蔽脚本期刊的前缀、级联中的单位提示（美国国家实验室、USGS、GFZ、
  Caltech）、数据仓库模式（IRIS、EarthScope）。见 [OTHER_FIELDS_zh.md](OTHER_FIELDS_zh.md)。
- **串行执行。**一次一篇，各站点有间隔。两次完整的文献库运行分别用 81 分钟处理 1,818 篇、90 分钟处理 2,092 篇
  （每篇约 2.6 秒）；一次 73 篇的 Wiley 重试用了 15 分钟，因为 Wiley 请求间隔 10 秒。
- **礼貌访问上的缺口。**Crossref 的间隔（0.25 秒）不区分检索请求，而检索的公开限额是每秒 1 次。实际运行中它们与其他
  站点的请求交错进行，但大批量的引文清单应当设置带 `mailto` 的 `SEISMO_HARVEST_UA`。NCBI E-utilities 的兜底查询没有
  发送 `tool` / `email` 参数。
- **只覆盖一部分的渠道。**`ethrc` 只服务一个机构的知识库；其他 DSpace 知识库只能通过 OpenAlex 的位置信息和 URL
  改写来覆盖。（`s2_oa`，即 Semantic Scholar，已经去掉：它在这些运行里试了 27 次，一份副本都没找到，现在的引擎也从没调用过它。）
